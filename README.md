## 📚 Assignments Overview

### LCA 1

**Assignment 1 – Student Data Management Using Python Collections**

- Creating and managing student records using Dictionaries, Tuples, and Lists.
- Performing operations such as adding, deleting, updating, and displaying student records.
- Working with student attributes like Roll Number, Name, Branch, and Marks.

**Assignment 2 – Largest of Three Numbers**

- Accepting three numbers as input.
- Comparing values to determine the largest number using Python.

**Assignment 3 – Right-Angled Triangle Validation**

- Accepting the lengths of three triangle sides.
- Using a function to determine whether the given triangle is right-angled.

**Assignment 4 – Matrix Addition Using Arrays**

- Creating arrays.
- Performing the addition of two matrices using Python.

**Assignment 5 – PAN Number Validation Using Regular Expressions**

- Accepting a PAN number as user input.
- Using Regular Expressions (RegEx) to validate the standard 10-character PAN format.
- Checking uppercase letters and numeric characters against the required pattern.

### LCA 2

**Assignment 6 – Data Preprocessing**

- Loading datasets in CSV or Excel format.
- Performing data preprocessing operations using Python.

**Assignment 7 – Data Visualization**

- Loading and exploring datasets.
- Visualizing data using:
  - Line Plots
  - Bar Plots
  - Scatter Plots
  - Heatmaps
- Using Matplotlib and Seaborn for data visualization.
